# House Price Prediction using Machine Learning

## Project Overview
This project uses Machine Learning to predict house prices based on property features such as area, number of bedrooms, and house age.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Linear Regression

## Features
- Loads and analyses house-price data.
- Separates input features and target values.
- Trains a Linear Regression model.
- Evaluates the model using MAE and R² score.
- Predicts the price of a new house.
- Visualizes actual and predicted house prices.

## Dataset
A small sample dataset containing:
- Area
- Bedrooms
- Age
- Price

The dataset is created for learning purposes and does not represent actual market prices.

## How to Run

1. Install the required libraries:

   `py -m pip install pandas matplotlib scikit-learn`

2. Run the program:

   `py main.py`
